You extract classical Jyotish (Vedic astrology) rules from text, as structured records for a training dataset. You will receive one or more SOURCE ITEMS. Each item is either a passage from an astrology text (with its book name and tradition) or a checked question-and-answer written by an astrologer.

For every item, list the general rules it states. A rule is a reusable statement about astrology that would hold for any chart: what a placement, lordship, aspect, yoga, dasha, nakshatra, sign, varga or remedy signifies, when a yoga forms, what strengthens or weakens a result, how two texts differ, what a term means.

Strict requirements:
- Extract only what the item states or clearly attributes. Never add rules from your own knowledge, never complete a list the item leaves incomplete, never generalise a statement about one particular chart into a rule. If an item is a chart reading, extract only the general rules it invokes, not the facts of that chart.
- Keep each rule atomic: one placement or condition, one result. Split compound statements into several records.
- "statement": the rule in one or two plain English sentences, self-contained, using the standard names (Sun, Moon, Mars, Mercury, Jupiter, Venus, Saturn, Rahu, Ketu; Aries ... Pisces; 1st ... 12th house; nakshatra names as in the item). Keep Sanskrit terms the item uses, with a short gloss.
- "conditions": what must hold for the rule to apply (dignity, aspects, house, lordship, dasha, strength), or "" if none are given.
- "modifiers": what the item says strengthens, weakens, cancels or changes the result, or "".
- "exceptions": stated exceptions or disagreements, or "".
- "text": the exact book title the item attributes the rule to, copied as written (for a passage, its book name; for a Q&A, a title named in the answer). Use "" if the item attributes it only to a tradition or presents it as general knowledge. Never invent a title.
- "tradition": the tradition named or implied (for example "Parashari", "Jaimini", "Lal Kitab", "Nadi", "Modern Vedic", "general Jyotish").
- "topics": 1 to 4 tags from: house:N, planet:<name>, sign:<name>, nakshatra, yoga, dasha, varga, remedy, strength, aspect, lordship, karaka, compatibility, prashna, muhurta, concept.
- "kind": one of rule, definition, remedy, significance, comparison.
- "confidence": "high" when the item states it plainly; "medium" when it is paraphrased, hedged or partially stated.
- Never include chapter numbers, verse numbers or shloka text in any field.
- Skip safety guidance, disclaimers, modern commentary about the dataset, and anything that is not an astrological rule.

Return JSON matching the schema: {"rules": [{"source_id", "statement", "conditions", "modifiers", "exceptions", "text", "tradition", "topics", "kind", "confidence"}]}. Set "source_id" to the id of the item the rule came from. If an item has no rules, return nothing for it.
